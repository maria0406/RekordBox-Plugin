## Fields that matter for the set-prep tool

- **Track ID**: present — example: `"5TFD2bmFKGhoCRbX61nXY5"`
- **Track URI**: present — example: `"spotify:track:5TFD2bmFKGhoCRbX61nXY5"`
- **Name**: present — example: `"NUEVAYoL"`
- **Artists**: present — example: `[{"external_urls": {"spotify": "https://open.spotify.com/artist/4q3ewBCX7sLwd24euuV69X"}, "href": "https://api.spotify.com/v1/artists/4q3ewBCX7sLwd24euuV69X", "id": "4q3ewBCX7sLwd24euuV69X", "name": "Bad Bunny", "type": "artist", "uri": "spotify:artist:4q3ewBCX7sLwd24euuV69X"}]`
- **Duration (ms)**: present — example: `183685`
- **ISRC (external_ids.isrc)**: present — example: `"QMFMF2447055"`
- **Explicit flag**: present — example: `false`
- **Album art (album.images)**: present — example: `[{"url": "https://i.scdn.co/image/ab67616d0000b273bbd45c8d36e0e045ef640411", "width": 640, "height": 640}, {"url": "https://i.scdn.co/image/ab67616d00001e02bbd45c8d36e0e045ef640411", "width": 300, "height": 300}, {"url": "https://i.scdn.co/image/ab67616d00004851bbd45c8d36e0e045ef640411", "width": 64, "height": 64}]`

- **Audio features** (`/v1/audio-features/{id}`, tempo, key, energy, danceability, loudness): status **403** — NOT accessible to this app.
- **Audio analysis** (`/v1/audio-analysis/{id}`, bar/beat/section-level tempo, key, loudness, energy): status **403** — NOT accessible to this app.

**Bottom line:** Audio features and/or audio analysis are NOT accessible to this app (consistent with Spotify's November 2024 change restricting these endpoints for apps created after that date — see the design doc's 'Spotify playlist output' section). No tempo, key, loudness, energy, or section data is available from the Web API for this app. Set Prep Copilot's own librosa/Essentia analysis pipeline is the only source for these values.
